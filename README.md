# Digital-Forensics-and-Data-Leakage-Investigation
Project Type: Hands-on Digital Forensics Investigation
Tools: FTK Imager, Autopsy, Windows
Project Overview
•	Conducted a simulated digital forensics investigation involving a USB drive suspected of containing confidential organizational information.
•	Created a mock evidence environment containing sample client records, salary documents, confidential project files, and dummy credentials.
•	Applied digital evidence preservation and forensic imaging procedures to support evidence integrity.
•	Used FTK Imager and Autopsy to examine the forensic image, identify potentially relevant artifacts, investigate hidden and deleted files, and reconstruct a timeline of file activity.
•	Prepared a structured forensic investigation report covering methodology, evidence handling, findings, limitations, and conclusions.
Specific Cybersecurity Skills Demonstrated
1. Digital Evidence Acquisition and Preservation
•	Prepared a controlled evidence source using dummy organizational data.
•	Applied forensic evidence-handling principles to minimize changes to the original storage device.
•	Created a bit-stream forensic image of a USB drive using FTK Imager.
•	Recorded and reviewed available MD5 and SHA-1 hash values to support evidence integrity verification.
•	Documented evidence acquisition details, including the source device, image format, examiner information, and acquisition time.
2. Digital Forensics Analysis
•	Created an investigation case in Autopsy and loaded a forensic image for examination.
•	Examined directory structures and file-system artifacts to identify files potentially relevant to suspected data leakage.
•	Investigated hidden folders and files containing simulated login credentials.
•	Examined deleted-file artifacts and attempted recovery of a simulated salary backup file.
•	Identified and categorized potentially relevant digital artifacts based on their contents, locations, and investigative significance.
3. Forensic Search and Artifact Identification
•	Performed keyword searches in Autopsy using terms such as confidential, password, salary, client, admin, project, and backup.
•	Examined search results to identify documents potentially containing sensitive information.
•	Distinguished potentially relevant artifacts from normal or unrelated files.
•	Assessed the relevance of recovered content while recognizing that the presence of a file alone does not establish malicious intent.
4. Timeline Reconstruction and Evidence Correlation
•	Examined file timestamps and available timeline features to reconstruct a sequence of file-related activity.
•	Correlated file names, locations, contents, and metadata to develop investigative leads.
•	Examined the relationship between confidential documents, simulated credentials, and deleted-file artifacts.
•	Identified additional evidence that would be needed to strengthen conclusions in a real investigation.
5. Incident Investigation and Reporting
•	Documented the investigation methodology, evidence sources, tools, and analytical procedures.
•	Prepared evidence tables linking artifacts to their locations, descriptions, and potential relevance.
•	Maintained a chain-of-custody record documenting evidence preparation, imaging, analysis, and reporting.
•	Identified investigation limitations and distinguished observed evidence from assumptions.
•	Developed evidence-based conclusions and recommendations for further investigation.
Key Actions Performed
•	Prepared: Created a controlled USB evidence source containing dummy confidential files.
•	Acquired: Used FTK Imager to create a forensic image of the evidence source.
•	Verified: Recorded available hash values to support integrity checks.
•	Examined: Loaded the forensic image into Autopsy and inspected its file structure.
•	Searched: Conducted keyword searches for simulated confidential information and credentials.
•	Investigated: Examined hidden and deleted-file artifacts.
•	Correlated: Used file metadata and timestamps to support timeline reconstruction.
•	Documented: Recorded findings, evidence-handling activities, and investigation limitations.
•	Reported: Structured the results into a digital forensic investigation report.
